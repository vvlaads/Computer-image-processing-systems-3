## 1. Теоретическая база

### 1.1. Классификация изображений

Классификация изображений — задача компьютерного зрения, заключающаяся в определении класса, к которому относится
входное изображение.

В данной работе рассматривается задача классификации автомобилей по типу кузова. Система должна определять один из трех
классов:

- Minivan — минивэн;
- Sedan — седан;
- SUV — внедорожник.

Для решения задачи используется сверточная нейронная сеть (Convolutional Neural Network, CNN).

### 1.2. Сверточные нейронные сети

Сверточные нейронные сети предназначены для обработки изображений и способны самостоятельно выделять характерные
признаки объектов.

Основными компонентами используемой архитектуры являются:

- **Сверточный слой (Convolutional Layer)** — извлекает признаки изображения, например контуры, текстуры и более сложные
  визуальные элементы.
- **Функция активации ReLU** — добавляет нелинейность, заменяя отрицательные значения на ноль.
- **Слой подвыборки MaxPooling** — уменьшает пространственный размер карт признаков, сохраняя наиболее значимые
  значения.
- **Полносвязный слой (Linear)** — использует извлеченные признаки для определения класса изображения.
- **Flatten** — преобразует многомерные карты признаков в одномерный вектор.

### 1.3. Функция потерь и оптимизатор

Для обучения используется функция потерь `CrossEntropyLoss`, предназначенная для задач многоклассовой классификации.

Оптимизация параметров сети выполняется с помощью алгоритма Adam с начальной скоростью обучения 0.001.

### 1.4. Метрики качества

Для оценки модели используются следующие метрики:

- **Accuracy** — доля правильно классифицированных изображений.
- **Precision** — доля правильных предсказаний определенного класса среди всех предсказаний этого класса.
- **Recall** — доля правильно найденных объектов класса среди всех объектов этого класса.
- **F1-score** — гармоническое среднее Precision и Recall.

Дополнительно используется матрица ошибок (Confusion Matrix), позволяющая определить, какие классы модель чаще всего
путает.

## 2. Описание разработанной системы

### 2.1. Постановка задачи

Разрабатываемая система принимает на вход изображение автомобиля и определяет тип его кузова.

В качестве результата система возвращает один из трех классов: `minivan`, `sedan` или `suv`.

### 2.2. Набор данных

Для обучения использован набор изображений Car Model Recognition Dataset, размещенный на платформе Mendeley Data.

Исходный набор содержит 1717 изображений:

| Класс   | Количество изображений |
|---------|------------------------|
| Minivan | 454                    |
| Sedan   | 1141                   |
| SUV     | 122                    |

Набор данных разделен на три части:

- Train (~70%) — используется для обучения модели.
- Validation (~15%) — используется для оценки качества в процессе обучения и выбора лучшей модели.
- Test (~15%) — используется для итоговой проверки качества модели на данных, не участвовавших в обучении и выборе
  модели.

Полученное распределение:

| Выборка    | Количество изображений |
|------------|------------------------|
| Train      | 1169                   |
| Validation | 256                    |
| Test       | 292                    |

Изображения предварительно приводятся к единому размеру 128 × 128 пикселей.

Для обучающей выборки применяются аугментации: случайное горизонтальное отражение, небольшое вращение и изменение
яркости и контрастности. Это позволяет увеличить разнообразие обучающих изображений и снизить риск переобучения.

Для валидационной и тестовой выборок используются только изменение размера и преобразование изображения в тензор.

### 2.3. Архитектура нейронной сети

В работе реализована сверточная нейронная сеть на основе `PyTorch`.

Архитектура состоит из трех сверточных блоков и классификатора.

| Слой | Операция                   | Параметры                         |
|------|----------------------------|-----------------------------------|
| 1    | Conv2d + ReLU + MaxPooling | 3 -> 16 каналов                   |
| 2    | Conv2d + ReLU + MaxPooling | 16 -> 32 канала                   |
| 3    | Conv2d + ReLU + MaxPooling | 32 -> 64 канала                   |
| 4    | Flatten                    | Преобразование признаков в вектор |
| 5    | Linear + ReLU              | 16384 → 128                       |
| 6    | Linear                     | 128 -> 3 класса                   |

На вход сети поступают RGB-изображения размером 128 × 128 пикселей.

После трех операций MaxPooling размер карт признаков уменьшается до 16 × 16, а количество каналов составляет 64.
Полученный тензор преобразуется в вектор размером 16384 элемента и передается классификатору.

### 2.4. Структура проекта

Назначение основных файлов:

- `config.py` — параметры обучения, пути к данным и настройки устройства.
- `model.py` — описание архитектуры сверточной нейронной сети.
- `dataset.py` — загрузка изображений и подготовка обучающей и валидационной выборок.
- `train.py` — обучение нейронной сети и сохранение лучшей модели.
- `evaluate.py` — оценка качества модели на валидационной выборке.
- `evaluate_test.py` — итоговая оценка модели на тестовой выборке.

## 3. Результаты работы и тестирования системы

В процессе разработки было проведено четыре эксперимента с различными вариантами обучения нейронной сети. Для сравнения
использовалась одна и та же валидационная выборка из 256 изображений.

### 3.1. Базовая модель

В первом эксперименте использовалась исходная архитектура сверточной нейронной сети без дополнительных методов
регуляризации и аугментации изображений.

Результаты на валидационной выборке:

- Train Accuracy: 100%.
- Validation Accuracy: 76.17%.

В процессе обучения наблюдался рост ошибки на валидационной выборке, несмотря на дальнейшее улучшение результатов на
обучающей. Это свидетельствует о переобучении модели: сеть хорошо запомнила обучающие изображения, но хуже обобщала
полученные признаки на новые данные.

### 3.2. Модель с аугментацией изображений

Во втором эксперименте в процесс подготовки обучающих изображений были добавлены аугментации:

- Случайное горизонтальное отражение.
- Случайное вращение изображения в пределах 10 градусов.
- Случайное изменение яркости и контрастности.

Цель изменений — увеличить разнообразие обучающих данных и снизить риск переобучения.

Результаты на валидационной выборке:

- Accuracy: 79%.
- Macro F1-score: 0.59.
- Weighted F1-score: 0.77.

| Класс   | Precision | Recall | F1-score |
|---------|-----------|--------|----------|
| Minivan | 0.68      | 0.70   | 0.69     |
| Sedan   | 0.84      | 0.90   | 0.87     |
| SUV     | 1.00      | 0.11   | 0.20     |

Матрица ошибок:

| Настоящий класс/Предсказание | Minivan | Sedan | SUV |
|------------------------------|---------|-------|-----|
| Minivan                      | 49      | 21    | 0   |
| Sedan                        | 16      | 152   | 0   |
| SUV                          | 7       | 9     | 2   |

### 3.3. Модель с аугментацией и весами класса

В третьем эксперименте сохранились аугментации изображений, но дополнительно были введены веса классов в функции потерь
CrossEntropyLoss.

Это изменение связано с дисбалансом набора данных: количество изображений седанов значительно превышает количество
изображений внедорожников. Веса классов позволяют сильнее учитывать ошибки при классификации менее представленных
категорий.

Результаты на валидационной выборке:

- Accuracy: 77%.
- Macro F1-score: 0.60.
- Weighted F1-score: 0.76.

| Класс   | Precision | Recall | F1-score |
|---------|-----------|--------|----------|
| Minivan | 0.71      | 0.59   | 0.64     |
| Sedan   | 0.81      | 0.91   | 0.86     |
| SUV     | 0.40      | 0.22   | 0.29     |

Матрица ошибок:

| Настоящий класс/Предсказание | Minivan | Sedan | SUV |
|------------------------------|---------|-------|-----|
| Minivan                      | 41      | 26    | 3   |
| Sedan                        | 12      | 153   | 3   |
| SUV                          | 5       | 9     | 4   |

### 3.4. Модель с аугментацией и Dropout

В четвертом эксперименте к аугментации изображений был добавлен слой Dropout с вероятностью отключения нейронов 0.5.

Dropout применяется для снижения переобучения: во время обучения случайная часть нейронов временно отключается, что
препятствует чрезмерной зависимости сети от отдельных признаков.

Результаты на валидационной выборке:

- Accuracy: 78%.
- Macro F1-score: 0.51.
- Weighted F1-score: 0.75.

| Класс   | Precision | Recall | F1-score |
|---------|-----------|--------|----------|
| Minivan | 0.75      | 0.60   | 0.67     |
| Sedan   | 0.79      | 0.94   | 0.86     |
| SUV     | 0.00      | 0.00   | 0.00     |

Матрица ошибок:

| Настоящий класс/Предсказание | Minivan | Sedan | SUV |
|------------------------------|---------|-------|-----|
| Minivan                      | 42      | 28    | 0   |
| Sedan                        | 10      | 158   | 0   |
| SUV                          | 4       | 14    | 0   |

### 3.5. Сравнение экспериментов и выбор модели

Сводные результаты экспериментов представлены в таблице:

| Эксперимент                | Accuracy | Macro F1-score |
|----------------------------|----------|----------------|
| Базовая модель             | 76.17%   | -              | 
| Аугментация                | 79.30%   | 0.59           | 
| Аугментация + веса классов | 77.34%   | 0.60           |
| Аугментация + Dropout      | 78.13%   | 0.51           | 

Для итогового тестирования была выбрана третья модель — с аугментацией изображений и весами классов.

Несмотря на то что модель с одной лишь аугментацией показала более высокую общую точность (79,30%), модель с весами
классов продемонстрировала немного более высокий Macro F1-score (0,60 против 0,59). Кроме того, она лучше распознаёт
наименее представленный класс SUV.

Таким образом, с учетом дисбаланса исходного набора данных третья модель была выбрана как более предпочтительная для
задачи классификации всех трех категорий автомобилей.

### 3.6. Итоговое тестирование выбранной модели

После выбора модели была выполнена итоговая проверка на тестовой выборке. Эти изображения не использовались ни для

Результаты на тестовой выборке:

- Accuracy: 78.77%.
- Macro F1-score: 0.59.

Матрица ошибок:

По результатам тестирования модель показала точность 78,77%. Наиболее уверенно система распознаёт седаны (Recall =
